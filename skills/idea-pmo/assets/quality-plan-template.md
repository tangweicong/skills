# 质量计划（按需）

> **PMP**：规划质量管理。  
> **默认**：T 模式用各阶段 `acceptance.md` 即可；**F** 或高合规场景启用本文件。

| 字段 | 值 |
|------|-----|
| 适用 | F / 高合规 T |
| 最后更新 | YYYY-MM-DD |

## 质量标准

| 领域 | 标准 | 验证方式 | artifact |
|------|------|----------|----------|
| 范围 | 与 charter/wbs 一致 | acceptance + analyze | acceptance.md |
| 文档 | artifact-index 交叉校验通过 | Round B / 阶段末 analyze | analyze 清单 |
| EXP | 成功信号满足 | review → DECISIONS | review.md |

## 质量活动

| 时机 | 活动 | 产出 |
|------|------|------|
| GATE-2 后 | artifact analyze | artifact-index 校验节 |
| 阶段末 | 验收 | acceptance.md |
| 项目末 | 收尾检查 | close-checklist（review 内） |
