# BRAINSTORM —— 初始想法草稿

> **这是你自己写的草稿，不是讨论文档。** 目的是用最低负担把想法说个大概，给后续讨论一个起点；不需要完整、不需要正确、不需要专业。
>
> **完成门槛**：5 个开放问句**至少答 3 个** + 自由叙述区非空，就可以进入下一阶段（苏格拉底澄清轮）。  
> **冻结时机**：进入**第一轮专家讨论**（轮次 02 落盘）后冻结，仅作历史留痕；在此之前，苏格拉底澄清轮中如果发现想法被问反了，可以回来改这份草稿。  
> **不写**：事实查证、专家视角、决定（INV/ORD/EXP）——这些属于轮次文件的职责，BRAINSTORM 越简短越好。
