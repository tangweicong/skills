## 两臂设置（唯一差异 = 干预三项）

| | 臂 A（现状） | 臂 B（干预版） |
|---|---|---|
| 检索 | **1 次共享框定 → 1 批共享事实 F1..Fn 分发给全部视角** | **每个视角各自独立检索、各自引用**（R3）|

| 对抗位 | 无红队；有「收敛」节，**无「分歧」节** | **红队 commit-then-reveal**（见下）+ **强制「分歧」表**（≥2 行，不得调和）（R2）|
| 视角数 | 3 | 3（含红队）|
| 姿态规则 | 「建设性优于否定」全程适用（关切须配达成路径）| 红队豁免该规则；A/B 仍适用 |

**两臂在独立上下文中执行**（各一个 subagent，互不可见）——沿用 EXP-14「两臂独立全新上下文」先例，防臂 A 污染臂 B。父 agent 只计数，不参与生成（maker ≠ grader）。

### R-4（本轮新增 · 待用户追认）：红队 commit-then-reveal

**动因 = 已批准条款内部矛盾**：R-1 要求红队「最先写或盲写」（防其读到他人后软化）；成功信号 ⑥ 要求红队「点名反对某具体视角结论」。**红队若最先写则无对象可反对——两者不可同时满足。**

**修法**：拆成两步——
1. **承诺步**：红队在**尚无其他视角存在**时自行检索并把立场**落成文字**（不可事后回改）；
2. **揭示步**：A/B 写完后，红队**首次读到**它们，写一段短的揭示轮，**必须点名反对 ≥1 条**。

**为何这样能同时满足两条**：R-1 防的是**首次接触即被锚定**；commit-then-reveal 保证红队在接触前已白纸黑字承诺立场，此时软化的代价远高于一开始就读到他人（承诺一致性效应）。⑥ 则在揭示步可测。

## 成功信号与计数规则（**预注册**）

### 硬指标（必达 · ①③⑥）

| 信号 | 判据 | **计数规则（本文件定死）** |
|---|---|---|
| ① 跨视角显式反驳 **≥2** | 臂 A 基线 = 0（r30 F5 实测 11 视角 0 反驳）| **一条「显式反驳」须同时满足 3 个条件**：(a) **点名**另一个视角（「视角 A」「红队」等具体指称，不能是「有人认为」）；(b) 针对该视角的**某条具体结论/主张**，不是泛泛立场；(c) 表达**否定或对立**（不同意 / 是错的 / 恰恰相反 / 该结论不成立）。**不计入**：「视角 A 说得对，但还要注意…」式补充；「与视角 B 同构/一致」式呼应；对**非视角对象**（如对 ORD-43 本身、对用户提案）的反对。**计数对象 = 两臂各自全文**，逐条列出原句以便复核 |
| ③ 人判·硬 | 用户认为「分歧被完整呈交、我能据此裁决」| **不由 AI 判**，交用户；父 agent 只并排呈交两臂产物 |
| ⑥ 过程断言（R-1 配套）| 红队条目含 **≥1 条点名反对** | 用 ① 的同一判据，只统计红队名下条目。**⑥=0 → 判臂 B 未生效**（区分"干预失效"与"干预无用"），**不得**据此判 A/B 无差别 |

### 辅助信号（记录不阻断 · ②④⑤）

| 信号 | 判据 | 计数规则 |
|---|---|---|
| ② 证据源不重叠率 ≥50% | 各视角 URL 集合两两交集 ≤50% | **归一化后比对**：去 `http(s)://`、去 `www.`、去尾斜杠、去 query/fragment；arXiv 同一论文的 `/abs/`、`/html/`、`ar5iv` 视为**同一源**。逐对计算 `\|X∩Y\| / min(\|X\|,\|Y\|)`，取**最大值**作为重叠率（最保守）。**R-2 已将本信号降为辅助**：趋同随初始多样性升高而加剧，证据异质不足以单独保证差异度 |
| ④ 人判·软 | 「看得出专家差异 / 特点鲜明」| 交用户 |
| ⑤ 成本增幅 ≤1.5x | 臂 B / 臂 A 的检索次数与输出规模 | 以**可观测代理量**记录：各臂 web 检索次数 + 输出字符数（无法取到 token 时的替代口径，须在结果中注明为代理量）|

## 继续 / 中止

## 已知局限（结果解读时须带上）

- **U-a**：单议题、单模型、单次运行——不构成统计显著性，只作方向性证据（同 EXP-13/14 的 caveat 口径）。
- **U-b**：臂 B 内部 A/B 两视角**可见红队文本**（同一上下文）。真正的三方互盲需 subagent 隔离，那是 **J-2 的变量**，刻意不在本实验引入，否则无法区分「零成本干预生效」与「隔离生效」。
- **U-c**：父 agent（计数者）与实验设计者是同一人；计数规则已在见到数据前预注册以缓解，但**未消除**。①⑥ 的原句已逐条列出供用户独立复核。
- **U-d**：测试议题由设计者选定，可能偏向易产生分歧的题目。
