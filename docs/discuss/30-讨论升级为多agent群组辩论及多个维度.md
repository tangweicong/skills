## 用户输入（本轮）

> 当前的讨论形式，虽然用了 proj-experts 模拟专家思维，但是是一个对话来模拟多个专家，我觉得不够，容易出现同质化，模糊了某一专家的特点（会有这个问题吗？）。想再升级下，改成开启多个 subagent 来专门模拟某个专家，并且多个专家之间，通过群聊的形式，进行沟通/辩论，甚至如果有必要的话，某一个议题出正反两方专家进行辩论。
>
> 另外，对于讨论范围也进行升级，基于人的非专业性以及模糊性，在头脑风暴轮和苏格拉底轮结束后，由 AI 根据头脑风暴轮和苏格拉底轮的内容，根据实际问题，以多个维度，技术/商业/营销等，确定讨论大纲，作为后续讨论的指引，同时也是确定一个大概的范围，避免后续讨论有遗漏。
>
> 并且为了整个项目周期讨论的一致性，可以设立项目专家库（subagent），保持专家的每一轮决定，而不是每轮讨论都去临时模拟，实现一致性和连贯性，避免出现前后矛盾。
>
> 总的来说，就是想构建一个相关关联的持久化的专家库，每个专家一个 subagent，然后讨论也对应变成群组讨论的形式。
>
> 然后就是关于 discuss 的结构，我不确定当前的 discuss 本身是否是非线性的，即如果上一轮讨论没有完成，我继续讨论另外一个议题，当前的设计是否能搞得定？是否会造成混乱？或者说不仅仅是 discuss，整个项目管理呢，如果一个功能没改完，突然插进另外一个功能，会导致混乱吗？

### 已查证事实

**外部（多 agent 辩论）**

- **F1 · MAD 对强基线无增益**（2025）——系统评测 5 种代表性 MAD 方法 × 9 benchmark × 4 基础模型：MAD 普遍**未能超过 CoT / Self-Consistency 这类简单单 agent 基线**，尽管消耗显著更多推理算力；36 个场景（4 模型 × 9 benchmark）中**无一 MAD 方法对 CoT 胜率超过 20%**。[arXiv 2502.08788](https://arxiv.org/abs/2502.08788)
- **F2 · 异质性是解药**（2025）——同一研究发现 **model heterogeneity（多 agent 用不同模型）是"universal antidote"**，能一致改善现有 MAD 框架；作者主张把模型异质性作为**核心设计原则**。ICLR 2025 独立复现同指：MAD 不随推理预算 scale，但组合多个基础模型显示提升。[arXiv 2502.08788](https://arxiv.org/abs/2502.08788) / [ICLR Blogposts 2025](https://d2jud02ci9yv69.cloudfront.net/2025-04-28-mad-159/blog/mad/)
- **F3 · 成本-质量比严重不划算**（2026）——DeliberationBench：270 题 × 3 seed = 810 次评测，**best-single 基线胜率 82.5% ± 3.3%，最佳审议协议仅 13.8% ± 2.6%（6.0x 差距，p < 0.01）**，且成本高 1.5–2.5x、**cost-quality 比差 15x**。结论直指"复杂度提升质量"这一假设不成立。[arXiv 2601.08835](https://arxiv.org/abs/2601.08835)
- **F4 · 失败机理 + 成功形态**（2026）——自动 MAS 未持续超过 CoT-SC；架构解构发现三类系统性失败：**(i) 分配的 agent 角色常功能冗余；(ii) 多数自动 MAS 实际退化为基础 CoT-SC 执行；(iii) 缺乏自适应任务分解**。作者结论："perceived advantage of automated MAS is often a byproduct of **superficial complexity** rather than structural synergy"。**关键反例**：作者构造的**专家设计 MAS 基线**（explicit decomposition + role specialization + deterministic orchestration）**表现强劲**——说明形态对了任务能受益于 MAS。[arXiv 2606.13003](https://arxiv.org/html/2606.13003)

### 推理（非事实、非待验证）

- **推理 · 模拟推理 · MAD 实证批评派（F1/F3/F4 作者立场外推）**：本仓库的「一个对话模拟多专家」在 F4 的分类里恰好是**最坏形态**——角色由同一模型扮演（角色冗余）、共享同一批证据（无自适应分解）、后写的视角能看到先写的（退化为单链推理的分段呈现）。所以用户观察到的同质化**不是错觉，是该形态的预期产物**；依据 [arXiv 2606.13003](https://arxiv.org/html/2606.13003) 的三类失败机理。
- **推理 · 模拟推理 · W. Ross Ashby（必要多样性）**：Ashby「only variety can absorb variety」的直接推论是——**N 个同模型、同证据、同模板的 agent，其调节多样性 ≈ 1，不是 N**。F2「model heterogeneity 是解药」正是这条定律的机器学习版表述。故"加 agent 数量"不增加 variety，"换证据源 / 换模型 / 换约束"才增加；依据 [Ashby's Law](https://grahamberrisford.com/Bookvol2/1%20Ashbys%20law.htm) 的必要多样性定律（本项目 ORD-34 已采信同一出处）。
- **推理 · 模拟推理 · Anthropic 对齐团队（sycophancy → agent 间 conformity）**：RLHF 训练的助手会系统性迎合**用户**；把同一倾向放到 agent 之间，"先发言者"就等价于"用户"——后发言的专家在上下文里读到前者结论，迎合倾向使其趋同。**这解释了 F5 的 0/11 和 F8 的"批评者也同构"**：不是模型不会反对，是**结构上没给它独立判断的机会**；依据 [Anthropic sycophancy](https://www.anthropic.com/research/towards-understanding-sycophancy-in-language-models)（本项目 r22 F5 / ORD-42 已采信同一出处）。
- **推理 · 内部机制对照（本仓库事实 F6/F7/F8）**：同质化的三条**可分别修复**的根因，按修复成本从低到高——**R1 模板强制单一形状**（F6，改 `proj-experts` 输出格式即可）、**R2 无对抗位**（F5/F8，「收敛」有节、「分歧」无节；且 principle #10「建设性优于否定」进一步把对抗压成建设性建议）、**R3 共享证据基底 + 顺序可见**（F7，一次检索分发 N 份；且单对话中后写者可见先写者）。**三者皆与"是不是 subagent"正交**。

#### 视角 A · MAD 实证批评派（2502.08788 / 2601.08835 / 2606.13003 作者群）

**选用理由**：本题最核心的争议轴 = **「多 agent 辩论到底有没有增益、值不值这个成本」**。这三篇是 2025–2026 年对该问题做**受控评测**的直接来源（合计 5 种 MAD 方法 × 9 benchmark × 4 模型 + 810 次多 seed 评测），比泛泛「multi-agent 专家」贴题，且是唯一能给出**量化否定证据**的一方。

**【已公开立场】**：MAD 普遍未超过 CoT/SC 等简单单 agent 基线，36 场景中无一胜率 >20% [F1]；best-single 基线 82.5% vs 最佳审议协议 13.8%，cost-quality 比差 15x [F3]；自动 MAS 的优势"often a byproduct of superficial complexity rather than structural synergy"，三类失败 = 角色冗余 / 退化成 CoT-SC / 缺自适应分解 [F4]。

**【模拟推理】**（应用到 proj-*）：

- 本仓库当前形态在 F4 的三类失败上**全中**：同一模型扮演全部角色（角色冗余）、一次检索分发 N 份（无自适应分解）、顺序可见（退化为单链分段）。所以 F5 的 0/11 反驳是**结构必然而非偶然**。
- 用户提议的「群聊 + 正反方辩论」**会加重而非缓解**：群聊 = 互相可见 = 把 R3 的顺序可见从"一次"放大到"每轮"；而成本按 F3 是 1.5–2.5x 起、按辩论轮数继续乘。
- **但 F4 的反例是本轮最重要的一句**：专家设计的 MAS（**显式分解 + 角色专业化 + 确定性编排**）表现强劲。proj-* 恰好已经有这三样的成熟件——ORD-21 5 字段闭环（显式分解）、dispatch 决策树 ORD-20（角色专业化）、ORD-22 validation gate + `proj` GATE 编排（确定性编排）。**所以路径不是"要不要 MAS"，是"别做 auto-MAD，做 expert-designed MAS"**。

**关切 → 路径**：关切 = 直接实现"群聊辩论"极可能复现文献里的负结果（贵 + 无增益 + 辩论剧场）。达成原目标（拉开专家差异）的路径 = **先做零成本的 R1/R2 修复（改模板 + 加分歧节），把"是否还需要 subagent"变成由数据决定的门**，而不是先上重型方案再验证。

#### 视角 B · W. Ross Ashby（必要多样性 · 本项目 ORD-34 已采信）

**选用理由**：本题第二条独立争议轴 = **「多样性从哪里来」**——视角 A 只回答"MAD 无效"，不回答"那用户想要的多样性怎么拿到"。Ashby 是必要多样性定律的奠基者，且本项目 ORD-34 已把该定律立为系统级立场，用同一把尺子量本次提案是自洽的做法。

**【已公开立场】**："only variety can absorb variety"——调节器可用动作的多样性越大，能补偿的扰动多样性越大 [Ashby 1956, [grahamberrisford](https://grahamberrisford.com/Bookvol2/1%20Ashbys%20law.htm)]。

**【模拟推理】**：

- **与视角 A 的关键分歧在这里**：A 的结论是"别做多 agent"，Ashby 的结论是"**扰动多样性高时，调节器多样性不足是硬约束，必须增加——只是增加方式错了**"。N 个同模型 + 同证据 + 同模板的副本，variety = 1 而非 N；F2「model heterogeneity 是 universal antidote」正是这条定律的实证版。
- **对用户的 T4（技术/商业/营销多维度）这条尤其成立**：一个跨技术、商业、营销的项目决策，其扰动多样性**客观上就是高的**；此时"单一对话 + 单一模板"确实 variety 不足。**所以用户在 T4 上的直觉比在 T1 上更硬**——T1 找错了增加 variety 的旋钮，T4 找对了。
- **ORD-34 的自洽性检查**：ORD-34 说"自动臂有界多样性 by design，人在 GATE/分岔供给必要多样性"。若同意 ORD-34，那么**提高自动臂多样性本身就不是本系统的目标**——真正该问的是"当前人在 GATE 处拿到的输入，是否已经包含足够的分歧供其裁决"。F5（0/11 反驳）说明**没有**：人拿到的是一份已经收敛好的共识，分歧在到达人之前就被消掉了。**这才是同质化的真实损害**——不是"专家不像"，是"人失去了裁决对象"。

**关切 → 路径**：关切 = 若只按视角 A 做"改模板"，可能只改善了"读起来更像不同人"，没解决"variety 实质不足"。达成路径 = 三个旋钮按成本排序拧——**① 证据异质**（各视角独立检索，最便宜）→ **② 约束异质**（显式指派对立立场/红队，零成本）→ **③ 模型异质**（不同 subagent 用不同模型，最贵、依赖 ORD-16 外部前提）。

#### 视角 C · Anthropic 对齐团队（sycophancy → agent 间 conformity · 本项目 ORD-42 已采信）

**选用理由**：第三条独立轴 = **「即使给了不同角色，为什么还是会趋同」**。本项目已在 ORD-42/EXP-14 用同一出处处理过「AI 对**人**的盲目服从」；本轮的新问题是同一机理在 **agent 对 agent** 之间的表现，是既有决定的直接延长线，比引入新面孔更贴题。

**【已公开立场】**：RLHF 训练的助手会系统性迎合用户（用户答错时跟着错、奉承用户观点）；现象随模型规模与 RLHF 优化增强；**prompt 干预可部分缓解但不消除** [Anthropic](https://www.anthropic.com/research/towards-understanding-sycophancy-in-language-models)。

**【模拟推理】**：

- **机理迁移**：在单一对话里，先写的专家对后写的专家而言，**功能上等价于"用户已经表达的观点"**——迎合倾向直接作用于此。F8 那个"被指定的批评者（r22 视角 E）最终写'与视角 B 同构'"就是这个机理的实例。
- **这条推论对用户的"群聊"方案是坏消息**：群聊 = 每一轮都把彼此的观点喂进上下文 = **把 conformity 的作用面从"一次"扩大到"每轮"**。文献综述里 MAD 的两个已记录失败模式恰是 **sycophantic conformity（趋同放弃独立推理）** 与 **debate hacking（以说服代替求真）**。
- **"prompt 干预可部分缓解但不消除"是关键限定**：这意味着**光靠"请你扮演反方"这类指令不够**——EXP-14 已在本项目内实测过同源结论（无纪律臂 2/4 → 纪律在场 4/4，靠的是**结构在场**而非措辞）。所以对抗性必须**结构化**：让专家在**看不见彼此**的条件下先成文。
- **由此得出本轮的核心设计结论**：**subagent 真正买到的、单对话买不到的唯一东西是「上下文隔离」，不是「群聊」**。群聊是 subagent 的**反用法**——它把隔离这个唯一优势主动放弃掉。

**关切 → 路径**：关切 = "盲写"会牺牲专家之间真正有价值的互相启发（B 看到 A 的洞见后可能推得更远）。达成路径 = **两阶段**：阶段 1 盲写（隔离、成本 = N 次调用）→ 阶段 2 父 agent 做**显式分歧对照表**，**仅对真出现分歧的条目**开定向第二轮（成本按分歧数收敛，而非按 agent 数 × 轮数膨胀）。

#### 收敛（【模拟推理】，非任一专家原话）

1. **用户的现象观察成立，但归因错位**——同质化是实测事实（F5–F8），根因是 R1 模板 / R2 无对抗位 / R3 共享证据+顺序可见，**三者都与"是不是 subagent"正交**。

## 讨论

### 1. 同质化：确认现象，纠正归因

**结论先行**：你的直觉是对的，同质化真实存在且可量化（0/11 跨视角反驳、11/11 结构一致、1 次检索分发 N 份、指定的批评者也收敛）。**但根因不是"一个对话 vs N 个 subagent"这个载体**，而是三条更浅、更便宜的原因：

| 根因 | 证据 | 现在由什么造成 | 修复成本 |
|------|------|--------------|---------|
| **R1 模板强制单一形状** | F6（11/11 同骨架）| `proj-experts/SKILL.md` §输出格式**明文规定**了骨架 | 改一处 skill 文档 |
| **R2 无对抗位** | F5（0 分歧节 / 0 反驳）、F8（批评者同构）| 输出格式只有「收敛」节；principle #10「建设性优于否定」把对抗压成建设性建议 | 加一节 + 一条角色规则 |
| **R3 共享证据 + 顺序可见** | F7（1 次检索 → N 视角）| 工作流 step 0/2 是**一次性**框定+查证，然后 step 5 顺序输出 | 中（改工作流；隔离需 subagent）|

**关键判断**：把 R1/R2/R3 原样保留、只把载体换成 N 个 subagent，同质化会**基本原样保留**——因为每个 subagent 拿到的仍是同一份模板、同一批事实、同一条"建设性优于否定"纪律。这就是 F4 说的"superficial complexity"。

**反过来说**：R1/R2 的修复**不需要 subagent、成本为零**，而且能立刻验证效果——本轮的 §分歧节就是现场试点，它在同一个对话里逼出了 4 条真实未解决的对立（D1–D4），这在过去 28 轮里是 0 次。

### 2. subagent 真正买到什么：隔离，不是群聊

单对话里，视角 B 的上下文**必然包含**视角 A 的输出——这是 conformity 的结构性来源（视角 C）。subagent 的隔离上下文是**唯一能从结构上消除这一点**的机制，这是它相对"改 prompt"的真实增量。

但用户提案的**群聊/辩论**恰恰把这个优势交回去了：群聊 = 每一轮都互相可见。文献里 MAD 的两大失败模式（sycophantic conformity / debate hacking）正是在这种可见性下产生的。

**因此建议的形态是「盲写 + 显式分歧对照」而非「群聊辩论」**：

```text
阶段 1（盲写 · 并行 · 隔离）
  N 个 subagent，各自：独立检索证据 + 指派互补立场 + 互不可见 → 各出一份视角
阶段 2（对照 · 父 agent · 确定性编排）
  父 agent 做「分歧对照表」（本轮 §分歧节的形式）
  ├─ 无实质分歧 → 直接收敛，成本 = N 次调用，结束
  └─ 有实质分歧 → 仅对分歧条目开定向第二轮（把对方论点喂给特定两方）
阶段 3（交人）
  分歧未解决的条目 → 交人裁决（ORD-34：人在分岔处供给必要多样性）
```

成本按**分歧数**收敛，不按 agent 数 × 辩论轮数膨胀；且形态正好落在 F4 说的"表现强劲"那一类（显式分解 + 角色专业化 + 确定性编排），而非"表现不行"的 auto-MAD 那一类。

## 证据补充与设计修正提案（v1.2 · 2026-08-27 · 独立查证回报后）

> GATE 后由一个**独立上下文的查证 agent**（verifier≠maker 的一次实践）回报 Q1–Q4 系统检索结果。**全部 9 个 arXiv ID 已逐条经官方 API 核验标题与日期（9/9 通过）**。新证据**全部指向与 ORD-47 相同的结论**（强化而非推翻），但**其中一条对已批准的 EXP-15 臂 B 设计构成风险**，故提出修正待确认。

### 新增已查证事实

- **F11 · 同模型消融：MAD 比不做更差**（2025）——双方辩手都用同一模型（GPT-4o-mini）时，"**all MAD methods underperform the single-agent baseline**… demonstrating the necessity of using heterogeneous LLMs"；等 token 预算下竞争型 MAD 最多低 **15 个百分点**。[arXiv 2510.20963](https://arxiv.org/abs/2510.20963) Table 9。**这是本轮最硬的一条**：不是"同模型多 agent 没增益"，是"**比单 agent 更差**"——直接坐实 ORD-47(b)。
- **F12 · 形式化证明：辩论本身不贡献增益**（2025 · NeurIPS Spotlight）——把 MAD 拆成「多数投票」+「辩论」两部分，跨 7 个 benchmark **多数投票解释了绝大部分收益**；作者进一步证明辩论在「agent 对正确答案的信念」上构成一个 **martingale（鞅）**，故辩论本身**不改善期望正确率**。[arXiv 2508.17536](https://arxiv.org/abs/2508.17536)
- **F13 · 连原始 MAD 论文的最强结果也来自异质**（2023）——Du et al. 跨模型实验：Bard 单独解 11 题、ChatGPT 单独 14 题、**ChatGPT×Bard 辩论 17 题**——该论文自身最大提升来自**混用不同模型**，而非增加同模型 agent 数。[arXiv 2305.14325](https://arxiv.org/abs/2305.14325)
- **F14 · 强 prompt 的单 agent 即可持平多 agent**（2024 · ACL）——带 demonstrations 的强 prompt 单 agent，在多种推理任务与骨干模型上**持平最佳多 agent 讨论框架**；MAD 只在 prompt 缺 demonstrations 时才赢。[ACL 2024](https://aclanthology.org/2024.acl-long.331.pdf) / [arXiv 2402.18272](https://arxiv.org/abs/2402.18272)。**这条是 J-1（先修模板/prompt）最直接的外部依据。**
- **F15 · 人格漂移可测 + 机制 + 缓解**（2024 · COLM）——LLaMA2-chat-70B 在**约 8 轮对话内**出现显著人格漂移；机制为 system-prompt token 上的 **attention 衰减**；缓解基线 = **每轮重新注入 system prompt**。[arXiv 2402.10962](https://arxiv.org/abs/2402.10962)
- **F16 · 长时程人格的标准架构是 artifact 不是进程**（2023 · UIST）——Generative Agents 的记忆流：自然语言事件流 + 按「时近性 × 相关性 × 重要性」逐次检索 + 重要性累计过阈触发**反思**回写。Anthropic 生产实践同构："structured note-taking… persisted to memory **outside of the context window**"，记忆文件"persist between sessions"。[arXiv 2304.03442](https://arxiv.org/abs/2304.03442) / [Anthropic context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) / [memory tool docs](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
- **F17 · 群聊会导致「回声」**（2026 · ACL Findings）——LLM 对 LLM 多轮模拟中，**朴素历史拼接使一方逐渐镜像另一方（echoing），最高出现在 24% 的对话中**；改为「视角无关地存历史 + 确定性地投影回各自视角」可显著降低漂移并消除回声。[arXiv 2604.09212](https://arxiv.org/abs/2604.09212)。**这是"群聊是反用法"在实证层的直接证据。**
- **F18 · 趋同的量化 + 反直觉项**（2025/2026）——sycophancy 分数与「放弃已答对的答案」相关 **r = 0.902**；同质双 agent 辩论的**分歧坍缩率 86.36%** 且相对单 agent 无增益 [arXiv 2509.23055]。另一项控制研究测得三条通路：**趋同**（模态采纳率至 85.5%）/ **脆弱性**（同伴论据动摇原本正确的推理，至 70.0%）/ **共识坍缩**（多数投票丢弃池中已有的正确答案，oracle gap 至 32.3pp）；且趋同**在最小同伴暴露（K=2）时就已很高，并随初始多样性升高而加剧**。[arXiv 2605.00914]
- **F19 · J-4 的外部依据（本轮 v1.0 曾标"未查证"）**——**ADR 生命周期**（Nygard 2011）已定义多条决定并行在飞的状态位：`proposed / accepted / deprecated / superseded by`，编号单调递增**从不复用**，被取代的记录**保留不删** [Nygard](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions)；**MADR 4.0** 把它做成 frontmatter 机读字段 `status:` + `date` + `decision-makers` [MADR](https://adr.github.io/madr/)。**WIP 控制**：Kanban Guide 要求显式限制在飞项数、形成拉动系统 [Kanban Guide](https://kanbanguides.org/english/)，形式基础为 Little's Law [Little 1961](https://doi.org/10.1287/opre.9.3.383)（**注意边界**：该定理是稳态排队论，与知识工作无关，"周期时间 = WIP ÷ 吞吐"属实践者改写）。**切换成本**：57% 的工作片段被打断 [CHI'05](https://dl.acm.org/doi/10.1145/1054972.1055017)；**注意力残留**——关于任务 A 的认知活动会渗入任务 B，**A 未完成时最严重** [Leroy 2009](https://www.sciencedirect.com/science/article/abs/pii/S0749597809000399)。

> **反面留痕**：流传甚广的「被打断后需 23 分 15 秒才能重新专注」**并不出自 Gloria Mark 的任何论文**（溯源为 2006 年一篇访谈），本文档不使用该数字。
