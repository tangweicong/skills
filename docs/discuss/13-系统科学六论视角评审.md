### 已查证事实

- **F1 · Good Regulator Theorem（Conant–Ashby 1970）**——调节器要"最优且最简"必须与被调系统**同态**；同态映射 `h: S→R` **会丢失信息**（模型是被调系统的有损像），定理由"使被调输出熵最小"推得。[Wikipedia](https://en.wikipedia.org/wiki/Good_regulator_theorem)
- **F2 · Requisite Variety（Ashby 1956）**——"only variety can absorb variety"；是**信息律**非物理律。[grahamberrisford](https://grahamberrisford.com/Bookvol2/1%20Ashbys%20law.htm)
- **F3 · 支配原理（Haken）**——慢序参量奴役快变量；序参量之间存在**合作或竞争**，决定最终涌现何种结构。[Wikipedia Synergetics](https://en.wikipedia.org/wiki/Synergetics_(Haken)) / [EPN 1976](https://www.europhysicsnews.org/articles/epn/pdf/1976/07/epn19760707p9.pdf)
- **F4 · 耗散结构（Prigogine）**——"dissipative structures … only exist in symbiosis with their surroundings"；近平衡时有序被破坏，远平衡时有序可维持并涌现新结构；靠**输出熵**维持。[Nobel 1977](https://www.nobelprize.org/prizes/chemistry/1977/press-release/)
- **F5 · cusp 分岔集（Thom/Zeeman）**——"As long as the state remains outside the cusp, behavior varies smoothly … When the control point passes all the way through the cusp, a catastrophe is inevitable"；分岔集内双稳 + 中间不可达 sheet + 滞后。[Zeeman 1976 PDF](https://www.imechanica.org/sites/default/files/1976%20zeeman%20catastrophe%20theory.pdf)
- **F6 · Shannon 信息论（1948）**——有噪信道有容量上限；冗余可纠错；接收端不确定性 = 熵（primary source: Shannon, *A Mathematical Theory of Communication*, 1948）。

#### 视角 A · Norbert Wiener / W. Ross Ashby（控制论 · 反馈与调节）

**选用理由**：用户指定「控制论」。本系统最核心的争议轴 = `proj` 的有界 loop 与 circuit breaker 是否构成**有效反馈调节**；Wiener/Ashby 是反馈控制 + 必要多样性 + good regulator 的直接奠基者，比泛泛「系统专家」贴题。

**【已公开立场】**：(1) Good Regulator Theorem——"every good regulator of a system must be a model of that system"，最简最优调节器与被调系统同态 [F1]；(2) Requisite Variety——"only variety can absorb variety"，调节器动作多样性须 ≥ 扰动多样性 [F2]。

**【模拟推理】**（应用到 proj-*）：

- **强匹配**：`proj` 的 `PLAN→EXECUTE→VERIFY→GATE?→RE-ROUTE→MEMORY` 是教科书式负反馈环；`verifier≠maker`（ORD-22 父跑 validation、sub-agent 不自评）= 反馈的**独立测量**；circuit breaker（>3 失败 abort）= 防自激振荡的**饱和限幅**；iteration budget（典型 2）= 阻尼；autonomy slider = 可调增益。这套件齐全且彼此扣合，是良序控制系统。
- **Good Regulator 命中**：`proj` 显式持有「host 给不了的跨 skill 状态」（ORD-30），其被调系统的**内部模型** = DECISIONS.md + （EXP-07b 引入的）机读 pipeline-state。这正是定理要求的「调节器内含被调系统模型」。**但**：定理同时说该模型是**同态**——必然**有损**（F1）。`proj` 的 CLASSIFY 只读「讨论状态 + 决定 + EXP」，EXP-07b 之所以要加机读 pipeline-state 块，正是因为发现这个模型对 CLASSIFY 而言**有损到不稳定**——这是项目自己已经撞上 good-regulator 的有损边界并打补丁，方向对。
- **Requisite Variety 的关切**：`proj` 自动臂的响应多样性 = {路由到 5 skill 之一 / GATE 停 / RE-ROUTE / circuit-break}。circuit breaker 把**大量不同失败模式塌缩成一个响应**（abort+交人）= 多样性**坍缩**。按必要多样性定律，自动调节器多样性不足以吸收项目情境的全部扰动——**项目实际上把「必要多样性」外包给了人**（高多样性调节器）。这与 Supervised-AI INV 自洽，但目前**只隐含在多条局部规则里，未被命名为系统级不变量**。

**关切 → 路径**：关切 = 「自动臂低多样性」若不点明，读者会误以为 loop 能自洽兜住所有情况。达成路径（不改机制，只显化）= 在 `proj` 写一条系统级表述：「**自动调节器按设计是有界多样性；人在 GATE / 分岔处供给必要多样性**」——把 Ashby 律变成显式设计立场，而非散落的 circuit-breaker 脚注。

#### 视角 B · Claude Shannon（信息论 · 信道/熵/冗余）

**选用理由**：用户指定「信息论」。本系统反复在处理「**有限带宽的人**」与「**多跳有损传递**」（DECISIONS→plan→manifest→prompt），Shannon 是信道容量 / 噪声 / 冗余纠错的奠基者，对应轴 = 信息保真与人信道带宽，独立于控制轴。

**【已公开立场】**：有噪信道有容量上限；冗余换纠错；接收端不确定性即熵 [F6, Shannon 1948]。

**【模拟推理】**：

- **亮点（项目已暗合 Shannon）**：① **human-read-manifest（≤5）/ GATE-S 人只读 ≤5** = 对「人」这条低带宽信道的**显式限速**——把人保护在信道容量内，是非常 Shannon 的设计；② **DECISIONS.md「先读本文即可」** = 共享**码本**，下游 skill 解码即可，免去重传 12 轮历史；③ **proj-experts 三档标签 + proj-shape 三分离** = 显式**信噪标注**（【原话】高保真信号 vs【模拟推理】重构信号），降低接收端 provenance 不确定性；④ **5 字段闭环 + self-contained prompt（APM）** = 对多跳有损信道加的**冗余/纠错码**。
- **关切（熵正在回灌活动核心）**：DECISIONS.md 的「最后更新」已是一段千字级流水句，单条 EXP 行也极长。**码本本身正在变成高熵噪声源**——人读「最后更新」blob 的解码成本陡增，恰恰违反项目自己倡导的信道容量精神。EXP-07b 的机读 pipeline-state 块是正确修向；但「最后更新」散文段仍需压缩。
- **关切（冗余 vs 同步成本）**：同一 ORD/INV/URL 在多文件重复（冗余利于纠错，好），但项目用**人工「互相同步」**维持一致——人工 parity 校验本身是**易错信道**。`validate_skills.py` 已做部分；可把 DECISIONS↔轮次 的一致性纳入机器校验。

**关切 → 路径**：达成「低熵活动核心」目标的路径 = (a) 活动 DECISIONS 头部改为**结构化机读状态块 +「最后更新」散文设硬上限**（把历史细节输出到变更日志/历史轮次——见 Prigogine 的熵输出）；(b) 把「DECISIONS 决定 ID ↔ 轮次同步」做成可机器断言的 lint，减少人工 parity。

#### 视角 C · Hermann Haken（协同论 · 序参量与支配原理）

**选用理由**：用户指定「协同论」。本系统最反直觉的成就 = **6 个独立 skill + 12 轮跨时间却保持一致**；Haken 序参量/支配原理正解释「少数慢变量如何让大量子系统自组织成一致宏观模式」，对应轴 = 协调机制（独立于反馈轴与信息轴）。

**【已公开立场】**：少数慢序参量（不稳定模）**奴役**大量快弛豫变量，使自由度约简、涌现宏观有序；序参量间合作或竞争决定结构 [F3]。

**【模拟推理】**（本轮最深的结构性洞察）：

- **DECISIONS.md（INV/ORD）= 全系统的序参量**。6 个 skill 在任一会话中的具体行为 = 被当前 DECISIONS 状态**奴役**的快变量。项目跨 6 skill / 12 轮的一致性，**不是靠紧耦合**，而是靠「所有 skill 都被同一序参量奴役」——改序参量则所有 skill 行为重组。这正是协同学意义上的自组织，是该架构最强的地方。
- **INV vs ORD = 两个时间尺度的序参量**：INV（仅用户显式推翻才变）= 最慢、最深序参量；ORD（可依证据修订）= 次慢。序参量分层清晰。
- **关切（支配原理要求时间尺度分离）**：奴役只在「序参量远慢于被奴役变量」时成立。12 轮里 ORD 从 01 涨到 31、EXP 到 08b，**设计期序参量自身在快速演化**（远平衡态成形，正常）；但对**已 stable 的流水线**，序参量应当沉降，否则宏观模式不稳。项目用 `shipped/stable` 标记部分区分了，但**「设计期（序参量成形）vs 使用期（序参量冻结、skill 被奴役）」未被显式立为纪律**。
- **序参量竞争**：INV-04（规划≠执行）与 `proj` 想端到端驱动之间存在潜在竞争；设计用「proj 调用 plan/run 而不合并」化解为**合作**——符合 Haken「合作型序参量稳定共存」。

**关切 → 路径**：路径 = 显式区分**设计期**（序参量仍在涨落成形，允许 ORD 增长）与**使用期**（对外发布的稳定流水线，序参量应冻结、只有 skill 行为随上下文变化）；为「使用期」定一条「非经 GATE 不新增 ORD」的沉降纪律（项目已有 GATE，只差点名）。

#### 视角 D · Ilya Prigogine（耗散结构论 · 远平衡/熵输出/涨落致序）

**选用理由**：用户指定「耗散结构论」。本系统是一套**活文档**，存活依赖持续维护能量；Prigogine 正解释「开放系统靠能量流与熵输出维持远离平衡的有序」，对应轴 = 系统的可持续性/抗衰退（独立于前述各轴）。

**【已公开立场】**：耗散结构只存在于与环境的共生中；远平衡靠持续交换物质/能量并**向外输出熵**维持有序；控制参数过阈值时**涨落被放大**致序 [F4]。

**【模拟推理】**：

- **整套 docs/ 是耗散结构**：靠人审 GATE、dogfood 跑、同步纪律这些**能量输入**维持低熵有序；一旦断能（停止维护）→ 衰退到平衡 = 文档漂移/陈旧。项目**内部已认知此点**——proj-survey 真相源优先级把 docs 压到接近最低、"docs 说的不等于代码做的"，与 Prigogine「近平衡有序被破坏」高度自洽。
- **order through fluctuations 命中**：EXP-xx 就是「涨落」。一次涨落（EXP-04 cost abort / EXP-06 partial / EXP-07 caveat）不杀死系统，而是被放大成结构变化（新 ORD / 降级路径 B）。「继续/中止 + 降级路径 B」正是让涨落**要么致新序（继续）、要么安全耗散（中止）**的机制——Prigogine 会认出这是分岔-涨落结构。
- **熵输出机制命中**：历史轮次文件冻结只读 + 变更日志 append-only = 把过时/废止决定**输出到历史**，使活动 DECISIONS 保持低熵。设计对。**但**只有在「活动 DECISIONS 真被保持干净」时才成立——而 Shannon 视角已指出活动头部正在回灌熵（千字 blob），**熵输出管道有倒灌**。
- **关切（能量来源单一）**：远平衡需持续能量流，而本系统几乎全部能量来自**单一维护者注意力**（处处「用户」、单一 dogfood）。Prigogine：耗散结构离不开环境。断能则无结构。

**关切 → 路径**：达成「低能耗也能维持有序」的路径 = **降低维持有序所需的能量**（自动化同步校验、压缩活动 DECISIONS、把一致性检查交给 lint），使结构能在更低能量流下存活——这与 Shannon、Haken 的路径**指向同一处**（见收敛）。

#### 视角 E · René Thom（突变论 · 控制参数/分岔集/滞后）

**选用理由**：用户指定「突变论」。本系统多处是**离散跳变**（GATE、plan/audit 分支、autonomy 档位），Thom 正解释「连续控制参数如何在分岔集处导致不连续跳变与滞后」，对应轴 = 不连续点的处理（独立于前述连续动力学各轴）。

**【已公开立场】**：行为由势函数极小决定；越过**分岔集**时状态在双稳间**不连续跳变**并带**滞后**（路径依赖）；分岔集内有不可达中间 sheet [F5]。

**【模拟推理】**：

- **proj-survey 的 plan/audit 分支 = 教科书 fold/cusp**：4 维打分（D1–D4）在阈值（total=6/8）附近的微小变化，会**翻转整条下游流水线**（plan vs audit）——这就是分岔集。Thom 会说：分岔集附近结果敏感且可能滞后。**项目已经本能地做对了**——R3「其余 → GATE-S 人审，默认 AUDIT」正是**在分岔集处放人**，因为自动分类器在 cusp 附近不可靠；且阈值 6/8 标注「可调超参，待真实难例校准」= 承认**分岔集位置本身不确定**。这是与突变论极漂亮的暗合。
- **autonomy slider = 控制参数**：上滑自主度，行为可在「有界↔无人值守」间不连续跳变；circuit breaker 阻止系统落入灾难 sheet（失控）。
- **滞后（hysteresis）关切**：一旦提交 plan 分支（brownfield handoff 已写 charter/WBS），再退回 audit 代价高（路径依赖/滞后）。设计用「不确定时默认保守 AUDIT」降低昂贵的错分支提交概率——好。**但**：若 plan 中途才发现 intent 其实不可重建，**缺一条显式「从 plan 回退 survey/shape」的边**；`proj` 的 RE-ROUTE + circuit breaker「推翻 INV/ORD → 回 proj-shape」**部分**覆盖，但 survey→plan 这条具体回退未点明。
- **反灾难的总体姿态**：JIT/rolling wave、有界 loop、小验收（works.all 非 works.any）= 刻意把系统**保持在单稳区（cusp 外）**、用小连续 diff 前进，避开双稳折叠区。这是与突变论一致的「主动远离分岔集」工程姿态。

**关切 → 路径**：路径 = 为「分支后发现判错」补一条显式回退边（survey/plan → 回 shape 重建 intent），并在 proj-survey/`proj` 标注「分支决定具滞后性，回退有成本 → 故分岔集处默认保守 + 必经人审」——把已有的保守默认上升为**对突变点的显式纪律**。

#### 视角 F · Ludwig von Bertalanffy（一般系统论 · 整体/涌现/开放/等价性）

**选用理由**：用户指定「系统论」。前 5 位各管一条机制轴，需要一位回答「这 6 个 skill 到底是不是一个**系统**、还是 6 个零件之和」；Bertalanffy GST 是整体性/涌现/开放系统/等价性的奠基者，担纲全局收束轴。

**【已公开立场】**：整体 > 部分之和（涌现）；开放系统与环境交换；**等价性（equifinality）**= 不同初态/路径达同一终态；层级与边界（GST 1968）。

**【模拟推理】**：

- **是真系统而非堆砌**：清晰**层级**（proj 在 5 专家之上）、显式**边界**（每个 skill「不触发本 skill」节就是边界定义）、**开放**（读写 DECISIONS = 与环境交换）。`proj` 编排带来**涌现**——「想法→落地闭环」这个价值是单个 skill 给不了的、由序列化涌现出来。
- **等价性命中**：双入口（greenfield 经 shape / brownfield 经 survey）**殊途同归**到 proj-plan 的 plan 状态 = equifinality 的好范例，说明系统按「终态」而非「单一路径」组织——稳健。
- **关切（边界靠散文维持）**：各 skill 边界由「不触发本 skill」等**散文约定**维持，而非机制——存在**边界泄漏**风险（某 skill 越权写 INV/ORD）。系统级看：除「DECISIONS 同步」外，**几乎没有管全局跨 skill 一致性的系统级不变量**（INV-01~04 多为 proj-plan 局部）。涌现要稳定，需要系统级约束，而非仅靠各 skill 自律。

**关切 → 路径**：路径 = 把现已散落的跨 skill 共性（如「任何 skill 先读 DECISIONS、原子回写、不越权改他人 artifact」）**提炼为一组系统级不变量**（候选：升一条 system-INV 或在 `proj` 立「pipeline 契约」节），让整体性有机制兜底而非全靠各 skill 自觉。

#### 收敛（【模拟推理】，非任一专家原话）

六视角并非各说各话，而是**从六个方向指向同三个跨切面结论**：

**收敛 1 · 序参量 DECISIONS.md 同时是最大优势与正在浮现的脆弱点**（Haken + Shannon + Prigogine 三镜同指）：
- Haken：它是让 6 skill 自组织一致的奴役序参量；Shannon：它是免重传的共享码本；Prigogine：它是必须向历史输出熵的低熵核心。
- 三镜**同时**指向同一风险：**活动 DECISIONS 头部正在累积熵**（千字「最后更新」blob + 人工同步负担），这会同时削弱它作为序参量（Haken）、信道码本（Shannon）、低熵吸引子（Prigogine）的三重作用。
- → 候选改进（非决定）：活动 DECISIONS 头部结构化（机读状态块，EXP-07b 已原型）+ 散文硬上限 + 把历史细节真正输出到变更日志。

**收敛 2 · 系统刻意把「必要多样性」外包给人**（Ashby + Thom + Bertalanffy 三镜同指）：
- 自动 loop 按设计是**有界多样性**（circuit breaker 塌缩失败、GATE 在不连续点停、分岔处默认保守）；人是恰好部署在突变点的**高多样性调节器**。
- 这套设计自洽且优秀，**但目前只隐含在多条局部规则里**，未被升为系统级立场。
- → 候选改进：在 `proj` 显式命名「自动调节器有界多样性 by design；人在 GATE/分岔供给必要多样性」。

**收敛 3 · 维持有序的能量是耗散结构的命门，降低维持能量是最高杠杆的稳健性改进**（Prigogine + Shannon + Haken 同指）：
- 结构仅在持续人力（同步纪律、dogfood）下维持有序；**降低「维持有序所需能量」**（自动化一致性校验、压缩 DECISIONS、减少人工 parity）是单点最高杠杆——且这正是收敛 1 的同一修向。

**一句话评审结论**：proj-* 在控制论（反馈环 + good regulator + 必要多样性外包）、协同论（DECISIONS 序参量奴役 + 双时标）、信息论（人信道限速 + 信噪标注 + 冗余纠错）、耗散结构（熵输出到历史 + 涨落经 EXP 致序）、突变论（分岔处放人 + 保守默认 + 反灾难小 diff）、系统论（层级/涌现/等价性）六个维度上**结构异常自洽、且多处与理论暗合到像刻意设计**；真正值得动手的不是机制缺陷，而是**活动 DECISIONS 的熵累积 + 跨 skill 一致性靠人工**这一处「三镜同指」的可持续性问题。

## 讨论

### 1. 为什么六论几乎都"正面命中"——这本身要警惕

六套理论高度自洽地解释了 proj-*，**可能有两种原因**，必须诚实区分（呼应 U1）：

1. **真命中**：项目设计者（grounded 借鉴 Anthropic/Osmani/Karpathy/PMBOK）独立收敛到的工程结构，恰与这些系统科学原理同构——因为它们本就是同一批关于「带反馈的开放复杂系统」的普适规律。这是**可信的一部分**：反馈环、verifier≠maker、序参量式单一真相源、人信道限速，确实是跨域反复出现的good patterns。
2. **镜像偏误**：六论框架解释力极强、近乎"万能套用"，**容易把任何结构都讲得通**。突变论历史上就因 Zeeman 的过度社会科学套用而受批评。所以「命中」需打折扣——本评审刻意在每视角都给了**具体关切**而非一味叫好，关切才是评审的真正增量。
