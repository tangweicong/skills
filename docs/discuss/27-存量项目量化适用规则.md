## 讨论

### 1. 直接回答：以自动生效为主，两类「可选轻量动作」，历史不回填

量化机制按**数据依赖**分成两类，适用规则因此不同：

| 机制 | 类 | 存量项目适用 |
|------|----|-------------|
| ORD-42 质疑条款 / ORD-44 可理解性 | 行为/规范类（SKILL.md 内嵌） | **自动生效**——下次会话即生效，零动作 |
| ORD-43 维度表 | 可选段（无数据依赖） | **自动可用**——新一轮讨论文档即用；历史轮次**不重跑** |
| ORD-41 挣得记账 | 数据类（依赖 plan 任务表 PV 列） | **向前生效**：新 phase 自动带 PV 列；在飞 phase 可选一次 2 分钟补列；**已结束 phase 不回填** |

### 2. 三个场景的具体操作

1. **继续使用中的存量项目（如小说项目）**：
   - 什么都不用做，下次会话自动获得 ORD-42/44 + 维度表可选段；
   - 若想当前在飞 phase 立即有挣得仪表：给该 phase plan 任务表加 PV 列（默认均权 1）+ 已完成任务标 ✓（EV 即刻入账）——**约 2 分钟，不需要重规划**；
   - 下一个重大决策点（就绪评估 / GATE）可选跑一次维度表 pass，探测遗留未决/冲突（这是存量项目最值得补的一次动作——F3 推理：风险在分歧漂移，不在缺历史数据）。
2. **已结束的历史项目**：**不补**。历史 EV 无预测价值（F1）；若未来重启 = 接管场景（下条）。
3. **接管（brownfield）项目**：既有 proj-survey → WBS 三态已免重规划（F3）；量化同规则 = 向前生效 + 决策点补量，无需一次性量化普查。

### 3. 原则（候选 ORD-45）

**量化是仪表不是档案**：量化机制向前生效，补量只补到「下一个决策点需要」的粒度（Goldratt 测量成本 + ORD-27 JIT）；唯一值得主动补的一次 = 决策点前的维度表 pass（突变论：分岔集前显式化漂移）。历史 phase 永不回填（EVM 挣得语义：sunk work 无预测价值）。

### 4. 落点（1 处 diff · 待 GATE）

- `skills/proj-survey/SKILL.md`：§6 分支产出表后加一行注记——「存量量化适用规则见 DECISIONS ORD-45：行为/规范类自动生效，数据类向前生效 + 决策点补量，历史不回填；接管项目 baseline 后首个决策点可选跑一次维度表 pass」。
